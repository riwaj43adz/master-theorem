# AgentOps Dashboard

A specialized observability platform for monitoring, debugging, and optimizing autonomous LLM agents.

## Core Capabilities
- **Real-time Trace Visualization**: See the "thought process" of your agents as it happens.
- **Cost & Token Tracking**: Monitor usage across OpenAI, Anthropic, and Gemini.
- **Latency Analysis**: Identify bottlenecks in your agentic chains.
- **Run Comparison**: Compare different model configurations and prompts.

## Tech Stack
- Next.js (App Router)
- Recharts (Data Visualization)
- Supabase (Database & Auth)
- Tailwind CSS
